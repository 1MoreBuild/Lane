# Lane website

Static source for the Lane product homepage at
[`getlane.pages.dev`](https://getlane.pages.dev).

The site has no build step or runtime dependencies. Serve this directory with
any static file server for local development. Production is deployed as the
`getlane` Cloudflare Pages project.

The primary download links intentionally point to GitHub Releases so the site
does not duplicate release metadata or artifacts.
